Flagship Case

흩어진 회사 데이터를
AI로 연결한 파이프라인

TAB — 영업·재무·운영·인사 데이터를 하나의 질문응답 시스템으로 만든 1인 프로젝트.

공개 버전 안내. 이 사례는 실제 재직 중인 회사의 사내 프로젝트를 바탕으로 하되, 회사명·실제 수치·내부 데이터는 모두 제거하고 더미화한 서술입니다.

배경 — 문제 정의

영업·재무·운영·인사 데이터가 각각 다른 스프레드시트와 담당자의 머릿속에 흩어져 있었습니다. "이번 달 판매량이 왜 떨어졌는가?" 같은 단순한 질문에도 여러 부서에 문의하고 수작업으로 취합해야 답할 수 있었고, 경영진 보고 한 건에 며칠씩 걸리는 일이 흔했습니다.

무엇을 했는가

이 문제를 해결하기 위해 사내 AI 데이터 파이프라인 프로젝트를 직접 제안하고, 승인 이후 혼자 기획부터 운영까지 리드했습니다.

  • 전체 데이터 흐름 설계 — Google Sheets에 흩어진 원본 데이터 → 자동 변환 스크립트 → 구조화된 지식 베이스 → AI 기반 분석 → Power BI/Excel 대시보드 + 경영진용 Q&A 툴로 이어지는 End-to-End 파이프라인 설계
  • 비용/기대효과 산정 — 초기 구축 비용, 예상 시간 절감 효과, 단계별 롤아웃 계획을 사업계획서 형태로 정리
  • 경영진 승인 확보 — 계획을 발표해 예산과 실행 승인을 받아냄
  • 파일럿 운영 — 경영진이 수작업 리포트 없이 KPI를 확인하고, 자연어로 질문해 답을 얻을 수 있는 환경을 구축·운영 중

왜 이 사례가 대표작인가

  • 1인 전주기 실행력 — 문제 발견부터 제안, 승인, 설계, 구축, 운영까지 기획자·분석가·엔지니어 역할을 혼자 소화
  • 경영 맥락 + 기술 역량의 결합 — 어디에 문제가 있고 무엇이 의사결정에 필요한지 아는 경영 감각과, 그것을 실제로 구현하는 데이터·AI 역량이 함께 필요한 프로젝트
  • 아이디어를 실제 검증까지 — 최신 AI 도구를 관망하지 않고 실제 업무 현장에 적용해 검증

이 경험이 이어지는 서비스

이 프로젝트에서 쌓은 역량은 아래와 같은 형태로 재현 가능합니다.

  • 흩어진 스프레드시트·문서 데이터를 하나의 구조화된 지식 베이스로 통합
  • AI 기반 자동 분석 + 자연어 질의응답 레이어 구축
  • 경영진이 매번 리포트를 요청하지 않아도 되는 자동 갱신 대시보드
  • 소규모 조직도 감당 가능한 예산·일정으로 설계

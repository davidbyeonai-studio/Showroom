# Showroom — David Byeon AI Data & Brand Studio

David Byeon의 퍼블릭 쇼룸 홈페이지 소스. GitHub Pages로 배포되는 정적 사이트(순수 HTML/CSS, 빌드 도구 없음)입니다.

- **소스 지식베이스**: 이 사이트의 콘텐츠는 비공개 Obsidian 볼트 [`davidbyeonai-studio/09_MyBrand`](https://github.com/davidbyeonai-studio/09_MyBrand)의 `65. Portfolio/`, `60. Business Plan/`에서 파생되며, 공개 전 회사 기밀·실데이터는 모두 제거·더미화됩니다.
- **구조**:
  - `index.html` — 랜딩 페이지 (Hero, 대표 사례, 서비스, About, Contact)
  - `portfolio/` — 케이스 스터디 상세 페이지
  - `assets/style.css` — 공용 스타일시트
- **배포**: GitHub Pages (Settings → Pages → Deploy from branch `main` / root)

내부 계획·미확정 전략 문서는 이 저장소에 절대 두지 않습니다 — 그런 문서는 비공개 볼트 저장소에만 존재합니다.
